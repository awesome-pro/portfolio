#
# Two usage vocabularies are declared, because they are different standards and
# cost one line each:
#
#   Content-Usage  — IETF aipref (draft-ietf-aipref-vocab / -attach), which
#                    updates RFC 9309 and is co-authored by Google's crawl
#                    lead. Labels train-ai / ai-use / search, values y / n.
#   Content-Signal — Cloudflare's 2025 vocabulary, read by Cloudflare's own
#                    products. Labels ai-train / ai-input / search, values
#                    yes / no.
#
# Both say the same thing here: this is a personal portfolio whose entire
# purpose is to be found, read, quoted and cited. Nothing on it is restricted.
# Neither vocabulary is enforced by anyone; they are preferences, and the
# wildcard Allow below is what actually governs crawling.

# ---------------------------------------------------------------------------
# Content Signals Policy
#
# As a condition of accessing this website, you agree to abide by the following
# content signals:
#
# (a) If a content-signal = yes, you may collect content for the corresponding
#     use.
# (b) If a content-signal = no, you may not collect content for the
#     corresponding use.
# (c) If the website operator does not include a content signal for a
#     corresponding use, the website operator neither grants nor restricts
#     permission via content signal with respect to the corresponding use.
#
# The content signals and their meanings are:
#
# search:   building a search index and providing search results (e.g.,
#           returning hyperlinks and short excerpts from your website's
#           contents). Search does not include providing AI-generated search
#           summaries.
# ai-input: inputting content into one or more AI models (e.g., retrieval
#           augmented generation, grounding, or other real-time taking of
#           content for generative AI search answers).
# ai-train: training or fine-tuning AI models.
# use:      what a crawler may keep and reuse after accessing the content —
#           immediate (store nothing) | reference (index, excerpt, link back)
#           | full (summarize and reproduce).
#
# ANY RESTRICTIONS EXPRESSED VIA CONTENT SIGNALS ARE EXPRESS RESERVATIONS OF
# RIGHTS UNDER ARTICLE 4 OF THE EUROPEAN UNION DIRECTIVE 2019/790 ON COPYRIGHT
# AND RELATED RIGHTS IN THE DIGITAL SINGLE MARKET.
# ---------------------------------------------------------------------------
